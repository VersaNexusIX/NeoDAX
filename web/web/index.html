NEODAX
MULTI-ARCHITECTURE BINARY ANALYSIS FRAMEWORK

Disassemble, decompile, and analyze binaries at the instruction level. Supports x86-64, AArch64, and RISC-V RV64GC across ELF, PE, and Mach-O formats with zero external dependencies.

x86-64 AArch64 RISC-V ELF PE Mach-O
# Clone & build
$ git clone https://github.com/VersaNexusIX/NeoDAX.git && cd NeoDAX && make
$ ./neodax -x ./binary
# Or via npm
$ npm install neodax
# Android / Termux
$ pkg install nodejs clang make git && git clone ... && make

Core Features
Disassembler
x86-64, AArch64, RISC-V RV64GC. Symbol resolution, C++ demangling, instruction group coloring.
-y -d -g -a
CFG Builder
Two-pass algorithm with jump-trick awareness. Loop detection via dominator analysis. Basic block extraction.
-C -L
Decompiler & SSA
ARM64 SSA lifting with versioned register assignments. Pseudo-C output from IR. RISC-V in progress.
-Q -D
Concrete Emulator
ARM64 and RISC-V RV64GC concrete execution. 32 GP registers, 256×4KB pages, CPSR flags, simulated heap.
-I
Entropy Analysis
Shannon entropy sliding window. Detects packed, encrypted, compressed sections automatically.
-e
JavaScript API
Native N-API addon. TypeScript declarations included. Web UI with 16 analysis panels. REST server.
npm install neodax
